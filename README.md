# Cypress OptiFabric
A WIP port of OptiPine to CypressFabric

## Features
- Made the lighting updater a bit less resource intensive (Almost Ported)
- Moved unnecessary low river code to the terrain generator, makes it less resource intensive (Ported)
- You can now enable and disable VBOs (Ported)
- Fully implemented the async chunk populator, shouldn't produce any artifacts (Ported)
- You can now create worlds using the McRegion world format, as well as convert all of them or just individual ones in-game directly (Ported)
- Fixed the absurd ambient music delay (Ported)
- And a few more tweaks! (Not sure)

## Problems
- Incompatibility with MoreIDs (Can't be fixed, OptiPine provides it own MoreIDs)
